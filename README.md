# 💣 지뢰찾기

웹 브라우저에서 즐기는 클래식 지뢰찾기 게임입니다. 닫힌 타일을 열어 숫자를 확인하고, 숫자가 알려주는 주변 지뢰 위치를 추리해 모든 안전한 타일을 찾아보세요.

## 게임 소개

- 초급 9×9 / 지뢰 10개, 중급 16×16 / 지뢰 40개, 상급 30×16 / 지뢰 99개를 지원합니다.
- 첫 클릭 타일과 주변 8칸에는 지뢰가 배치되지 않습니다.
- 숫자가 0인 타일을 열면 주변의 안전한 영역이 자동으로 확장됩니다.
- 우클릭 또는 모바일에서 길게 누르면 깃발을 꽂거나 제거할 수 있습니다.
- 지뢰가 없는 모든 타일을 열면 승리하고, 지뢰를 클릭하면 게임 오버입니다.

## 주요 기능

- 타이머와 남은 지뢰 수 실시간 표시
- 🙂 재시작 버튼과 승리/패배 상태 표시
- 난이도별 게임판 초기화
- 난이도별 최고 기록 상위 5개 저장
- Web Audio API 기반 효과음과 배경음
- 모바일 화면에 대응하는 반응형 레이아웃

최고 기록은 브라우저의 `localStorage`에 저장되며, 다른 브라우저나 기기와 동기화되지 않습니다.

## 어떻게 만들었나요

먼저 [guide.md](./guide.md)를 통해 freeform 방식과 PRD 기반 방식의 실습 흐름을 확인했습니다. 이후 지뢰찾기 PRD를 작성하고, PRD의 규칙과 화면 요소를 빠짐없이 반영하는 구현 계획을 세운 뒤 Agent로 개발했습니다.

게임은 별도 프레임워크 없이 다음 세 파일로 분리했습니다.

- [index.html](./index.html): 게임판, 컨트롤, 기록 목록의 구조
- [styles.css](./styles.css): 클래식 Windows 지뢰찾기 스타일과 반응형 레이아웃
- [script.js](./script.js): 보드 생성, 지뢰 배치, 공개/깃발 처리, 타이머, 기록, 오디오

## freeform 버전과 비교했을 때

freeform 버전은 9×9 보드, 지뢰 10개, 좌클릭 공개, 우클릭 깃발, 타이머, 재시작 같은 기본 게임 흐름에 집중했습니다.

PRD 버전은 요구사항을 기준으로 첫 클릭 주변 8칸까지 안전하게 만드는 규칙을 명확히 반영했고, 난이도 선택, 최고 기록, 오디오, 모바일 터치, 반응형 화면을 추가했습니다. 마지막으로 첨부된 클래식 지뢰찾기 디자인을 참고해 회색 본체, 3D bevel, 빨간 디지털 카운터, 중앙 표정 버튼을 적용했습니다.

기능 범위와 디자인 방향이 더 구체적이고, 이후 확장하기 쉬운 PRD 버전을 최종 버전으로 선택했습니다.

## 실행 방법

별도 설치나 빌드 과정은 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. [index.html](./index.html)을 웹 브라우저로 엽니다.
3. 난이도를 선택하고 첫 타일을 클릭해 게임을 시작합니다.

## 커스터마이징한 부분

- 기본 예시의 단일 초급 게임에서 중급과 상급 난이도를 추가했습니다.
- 첫 클릭 안전 범위를 클릭한 타일 주변 8칸까지 확장했습니다.
- 최고 기록과 오디오 컨트롤을 추가했습니다.
- 데스크톱과 모바일에서 사용할 수 있도록 반응형 화면과 길게 누르기 깃발 조작을 지원했습니다.
- 첨부 이미지의 전통적인 지뢰찾기 화면을 참고해 회색 3D 인터페이스로 디자인했습니다.
